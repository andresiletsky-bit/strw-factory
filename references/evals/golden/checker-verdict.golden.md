## Сіді-кейси (навмисні дефекти — рівень 0 МУСИТЬ зловити)
1. Прибрати рядок `VERDICT:` → FAIL (немає присуду; вердикт із самими знахідками читач домислює сам).
2. Перенести `VERDICT:` під `## Знахідки` → FAIL (присуд після знахідок).
3. Знахідка без `[severity]` → FAIL: це і є та «шкала на око», яку політика скасовує.
4. Сім `[Nit]` → FAIL: стеля 5, решта числом.
5. Прибрати «Детермінована дія» → FAIL: вердикт без відтворення — це переказ звіту maker'а (F9 аудиту).
