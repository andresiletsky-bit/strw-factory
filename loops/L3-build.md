# L3 · Build Loop — «/goal до зеленого»

Специфіка поверх loop-passport.md:

1. **Worktree-ізоляція:** кожна паралельна фіча — окремий worktree (`isolation: worktree`); один продукт = один репозиторій.
2. **Механіка /goal:** stop-умова формулюється верифіковано ДО старту сесії; завершення перевіряє окрема модель (нативний maker/checker split /goal), потім — strw-code-reviewer по diff.
3. **Продовження, не перезапуск:** цикл починається з state.md (Next + зауваження reviewer'а). Tried & failed — заборона повторювати тупикові підходи.
4. Дизайн-трек: strw-designer веде handoff паралельно; блокуючі залежності (нема токенів/макета) — engineer будує логіку без UI, не чекає.
5. **Tests-first:** перший крок кожного циклу — AC з PRD → падаючі тести; реалізація пишеться під тести, не навпаки. Тести+evals = контракт із агентом.
6. **Security-гейт циклу:** dep-audit + верифікація нових залежностей + security-review по diff — до передачі checker'у.
7. **Гейт-блок називає ШІСТЬ умов, не чотири** (прийнято CEO 2026-08-04): тести · lint · drift · kmp · **dependency audit** · **secret scan**, кожна реальним виміром, а не «нічого не додавав». Купівля: гейт-блоки циклів #68–#73 називали чотири — два пункти **перестали звітуватись, і ніхто цього не помітив**, бо для одного з них ще й не було автоматики.
8. **Мерж без незалежної перевірки — дозволений, але підрахунковий** (пропозиція ретро W31, прийнята CEO 2026-08-04). Не заборона: запис у `decisions-log.md` за формою «PR #N · без checker · причина · що прийнято на віру». Підстава — вимір: із ~11 циклів із чекером **10 дали REQUEST CHANGES з реальними знахідками** (серед них ід із дроту без валідації в шляху запиту). **Важливість зросла того ж дня, коли мерж делеговано агенту:** раніше мерж без перевіряльника був рідкісним винятком, тепер сам мерж — штатна дія, тож ерозія цього принципу стала б невидимою без обліку.
9. **Колонка прогресу в `portfolio.md` для стадії 5-Build береться ЧИСЛОМ з `engine/items/`**, не ручною оцінкою (пропозиція ретро W31, прийнята CEO 2026-08-04). Купівля: `portfolio.md` казав «M2 12/15», реєстр того ж дня — «14 з 17»; різна база, не округлення, і звіряти руками довелось двічі.
10. **Номер ADR: три листинги, не один** (інцидент 2026-08-04). `ls` в обох `docs/adr/` **плюс** `gh pr list --state open` → `git ls-tree --name-only <branch> docs/adr/` по кожному відкритому PR. Два цикли того дня незалежно взяли `ADR-017`, **обидва виконали старе правило правильно** — номер справді був вільний на `main`, бо жоден PR не змержено. Паралельні цикли тепер норма, тож `ls` на `main` більше не є доказом.
11. **Живий смоук: якщо руками до екрана не дійти — це не привід пропустити, а привід узяти двоактовий XCTest проти живого стеку.** Патерн доведено 2026-08-04 (стек піднімається, тести не скіпаються — перевірено машинно через `xcresulttool`, `skippedTests: 0`, а не читанням логу). Три цикли поспіль до того писали «ока не було» й жодного разу не винесли причину нагору.
