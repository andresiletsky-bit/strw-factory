# L1 · Discovery Loop — «ранкова розвідка»

Виконується через strw-loop-run за загальним життєвим циклом (loop-passport.md). Специфіка:

1. **Джерела за пріоритетом:** Knowledge Library (якщо є свіже) → web-тренди/форуми → маркетплейси → прогалини конкурентів наявних продуктів портфеля.
2. **Ротація фокусу:** кожен запуск — інший кут, по черзі запусків: болі/спільноти → тренди/ринки → конкуренти/ніші. Не за днем тижня — запусків менше, ніж днів, і прив'язка до дня консервувала б пропущені кути.

2a. **ТРИ ТРЕКИ, РІЗНІ ПЛАНКИ, ОДИН ЗАПУСК.** Рішення CEO 2026-08-08 після трьох тижнів поспіль із нулем карток. Причина нуля — не зламані фільтри: три останні запуски вбили кандидатів правильно, щоразу знаходячи наявний **безкоштовний** тариф, що вже закриває заявлений розрив. Висновок петлі збігся з незалежним висновком CEO про ринок: ніша споживчого трекера, який одна людина може зібрати, вже зайнята — і зайнята безкоштовно.

   | Трек | Що шукає | Планка приймання |
   |---|---|---|
   | **A · свій продукт** | чи не входить продукт портфеля в ту саму пастку: безкоштовний конкурент, що вже закриває його обіцянку | знахідка з посиланням, не враження |
   | **B · розширена ніша** | B2B, prosumer, інструменти для операторів — де безкоштовний тариф не є дефолтом ринку, а готовність платити доведена бюджетом, не ентузіазмом | чинна: **≥2 незалежні первинні сигнали** |
   | **C · латентне** | те, чого ще немає, або про що інформації не знайти | сигнали **НЕ** потрібні — потрібна **дешева проба, що вміє спростувати ідею за тиждень** |

   **Чому трек C має іншу планку, а не послаблену.** Правило «≥2 первинні сигнали» і нова ідея несумісні за побудовою: про те, чого ще немає, ніхто не скаржиться, тож відсутність інформації прирівнялась би до відсутності попиту. Але прибрати планку не можна — саме вона тричі поспіль спрацювала правильно. Тому планка **замінюється**: для треку C доказом слугує не попит, а існування дешевого способу довести хибність. Це те саме правило, що в `decision-protocol.md`: найдешевша проба, яка вміє почервоніти. **Немає такої проби — ідея не заводиться**, якою б привабливою не була.

   **Ротація, а не збільшення.** Один трек на запуск, по черзі A → B → C. Бюджет петлі не росте: рішення CEO того ж дня — «перестати починати, почати закінчувати», і три треки щоразу суперечили б йому. Ротація ж не дає жодному з трьох законсервувати власну сліпу зону.

   **Стеля треку C: одна жива гіпотеза.** Друга не відкривається, доки перша не спростована або не перейшла у звичайну картку. Інакше трек C стає генератором фантазій, а не розвідкою.
3. Порожній результат — нормальний: тихий архів, один рядок логу.
